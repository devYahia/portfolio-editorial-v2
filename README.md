# devYahia Portfolio

A high-end, editorial-style technical presence designed for computer engineering and backend systems. This portfolio targets freelance clients and industry partners with a focus on honest, value-driven positioning and high-quality visual design.

## Features

- **Typography System**: Professional "Rule of Three" font stack utilizing DM Serif Display, DM Sans, and JetBrains Mono.
- **Hero Section**: Dynamic background featuring an interactive monochrome particle network and subtle mesh gradients.
- **Projects**: Curated selection of completed engineering projects (e.g., ASTRA bot, InnoFab, and more).
- **Architecture**: Built with Next.js 15 (App Router), TypeScript, and Tailwind CSS v4.
- **Interactivity**: Fluid animations using Framer Motion and custom glassmorphism effects.

## Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion, tsParticles
- **Deployment**: Coolify CI/CD

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Design Philosophy

The site follows a "Technical Editorial" aesthetic, prioritizing generous whitespace, high-contrast typography, and intentional, subtle motion. It avoids generic AI-generated design patterns in favor of a distinctive, premium feel.
